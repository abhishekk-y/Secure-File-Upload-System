# SecureVault visual direction

## Design read

SecureVault is a small private file vault for students and everyday users. The public page should feel editorial and composed; the workspace should make upload state, file ownership and security results quick to read.

## Dials

- Energy: 2. A confident serif headline establishes character without obscuring the task.
- Rhythm: 3. The landing page moves from an editorial opening to a compact process strip, then a technical security list. The vault keeps a stable utility layout.
- Motion: 2. The transfer path animates once to explain the file journey. Control feedback stays brief; no decorative loops run indefinitely.

## Design decisions

- Palette: warm paper and charcoal frame the interface; muted plum marks the brand and selected navigation; brick red is reserved for meaningful warning and error states. This keeps security details legible while retaining the existing SecureVault mark.
- Type: Georgia is used for public display headings to give the neo-classical direction a recognizable editorial voice. Arial remains for dense workspace labels and data tables because it is widely available and readable without loading remote fonts.
- Layout: the landing page uses a two-column editorial opening and a true three-part user workflow. The application keeps its navigation and file table predictable so routine actions remain easy to find.
- Dashboard hierarchy: muted category tints distinguish documents, images and the complete file list; table hover and keyboard focus mark the row being acted on. These signals support filtering and selection rather than decoration.
- Edges and depth: the public page uses fine rules and open space; workspace actions use square corners and firm outlines to make controls feel direct. Offset shadows show the file, vault and share layers in the illustration; interaction shadows stay limited to the primary action and selected tile.
- Motion: one finite arrow trace clarifies the upload-to-vault illustration. Hover and focus transitions confirm interaction; reduced-motion preferences disable animation.
- Illustration: the existing file-to-vault drawing describes SecureVault's real flow. Its sample file is explicitly labeled as an illustration, not a user or security result.
